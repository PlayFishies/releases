# Fishies downloads

Fishies is a living social aquarium. Raise one fish at a time, feed it by hand, and watch it
grow on server time, whether you are watching or not. Play in the browser at
[fishies.lol](https://fishies.lol), or install it from here.

**[Latest release →](https://github.com/PlayFishies/releases/releases/latest)**

| You have | Download |
| --- | --- |
| Windows | `Fishies-Setup-<version>.exe` |
| Windows, 32-bit | `Fishies-Setup-<version>-32bit.exe` |
| Windows on ARM | `Fishies-Setup-<version>-arm64.exe` |
| A Mac (Apple Silicon or Intel) | `Fishies-<version>-macos-universal.dmg` |
| Linux, any distribution | `Fishies-<version>-linux-x86_64.AppImage` |
| Ubuntu, Debian, Mint | `fishies_<version>_amd64.deb` |
| Fedora, openSUSE | `fishies-<version>-1.x86_64.rpm` |
| Android | `Fishies-<version>-<build>.apk` |

Also on [Google Play](https://play.google.com/store/apps/details?id=lol.fishies.f) and
[itch.io](https://playfishies.itch.io/fishies).

This repository holds releases only. Bugs and ideas go to
[PlayFishies/feedback](https://github.com/PlayFishies/feedback).
